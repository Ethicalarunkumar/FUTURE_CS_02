# 🛡️ FUTURE_CS_02  
### **SOC Internship Project – Security Alert Monitoring & Incident Response (Splunk)**

This project simulates the work of a Security Operations Center (SOC) Analyst.  
Using **Splunk Enterprise**, I analyzed simulated logs, identified suspicious activities, and created an **Incident Response Report** with timeline, screenshots, and classifications.

---

## 📌 **Project Overview**
This internship task focuses on:

- Monitoring and analyzing security alerts
- Detecting suspicious activities using Splunk Enterprise
- Examining authentication, network, malware, and generic log events
- Performing incident categorization (High, Medium, Low)
- Preparing a professional Incident Response Report
- Documenting the timeline of attacks
- Creating dashboards and search queries

---

## 🛠️ **Tools Used**
- **Splunk Enterprise (Free Trial)**
- Simulated SOC Logs (100 events)
- Windows 11
- PDF Report & Markdown Documentation

---

## 📁 Folder Structure

### **📂 SPLUNK_REPORT/**
Contains documentation, search queries, and structured findings.

### **📂 SCREENSHOOTS/**
Organized sub-folders showing screenshots of Splunk searches:

- **AUTH_FAILURE/**  
  > Failed logins detection  
- **AUTH_SUCCESS/**  
  > Successful authentication events  
- **INDEX="MAIN"/**  
  > Full log index  
- **INDEX=*/**  
  > Raw indexwide search  
- **MALWARE_DETECTED/**  
  > Malware alerts  
- **NETWORK_CONN/**  
  > Incoming/outgoing network connections
